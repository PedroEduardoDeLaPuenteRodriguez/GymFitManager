GymFit Manager - Rediseño (Tarea 6-7, Parte 2)

IntelliJ: File > Open > carpeta GymFitManager (se detecta como proyecto Maven).
Ejecutar: Maven > Plugins > javafx > javafx:run   (o ejecutar gymfit.Main)
Scene Builder: clic derecho en src/main/resources/gymfit/gymfit.fxml > Open in SceneBuilder
Requisitos: JDK 17+ (JavaFX 21 se descarga con Maven).
